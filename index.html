สร้าง LINE Official Account + เปิด Messaging API

ที่ LINE Developers Console → สร้าง Provider → Channel แบบ Messaging API → แท็บ Messaging API กด Issue Channel access token (long-lived) แล้วคัดลอกไว้ (LINE Notify ปิดบริการแล้วตั้งแต่ 31 มี.ค. 2025 จึงต้องใช้วิธีนี้)

สร้าง Apps Script

เปิด Google Sheet → ส่วนขยาย → Apps Script → วางโค้ดจากไฟล์ apps-script/Code.gs แทนของเดิม

ใส่ Script Properties

การตั้งค่าโปรเจกต์ (⚙️) → Script properties → เพิ่ม LINE_CHANNEL_TOKEN = token จากขั้นที่ 1 และ API_KEY = รหัสอะไรก็ได้ (กันคนอื่นกดส่ง)

Deploy เป็น Web App

Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone → คัดลอก URL มาใส่ในช่องด้านบน

ผูกกลุ่ม LINE

ใน Console ตั้ง Webhook URL = URL เดียวกัน แล้วเปิด Use webhook · เชิญบอทเข้ากลุ่ม บอทจะตอบ ID กลุ่ม → ใส่เป็น LINE_TO ใน Script Properties (ถ้าไม่ใส่ จะส่งแบบ broadcast ถึงเพื่อนทุกคนของบอท)

เปิดการแจ้งเตือนอัตโนมัติ

ใน Apps Script เลือกฟังก์ชัน setup แล้วกด Run หนึ่งครั้ง (อนุญาตสิทธิ์) ระบบจะตั้งเวลาเช็คทุกวัน 08:00 น. เวลาไทย จากนั้นกด “ส่งข้อความทดสอบ” เพื่อยืนยัน
